UI concept: “School Notebook / Tactical Paper”

The whole game looks like a physical old-school game sheet, but with a modern digital interface. Slightly imperfect lines, paper texture, handwritten numbers, stamped indicators, and subtle animations. It fits Bingo/Housie without looking like a generic gambling game.

Prompt:

Design a unique 2D Bingo game interface called “BINGO”, built around the visual concept of an old school notebook/game sheet transformed into a polished digital game.

The interface should feel like a physical paper game being played on a desk, not a casino, arcade, or generic mobile game. Use a warm off-white paper background with extremely subtle paper grain, thin graphite-like borders, imperfect hand-drawn lines, tiny pencil marks, crossed-out numbers, margin notes, and occasional red correction marks. Keep the aesthetic sophisticated and restrained rather than childish.

The main screen is divided into two large opposing Bingo boards: PLAYER on the left and COMPUTER on the right. Each board is a clean 5×5 grid containing the numbers 1–25, but the number arrangements are different. The grids should look like printed game cards taped or pinned onto the notebook.

In the center between the boards, create a small “CALL” area resembling a physical number-drawing mechanism. The currently called number appears as a large handwritten number inside a slightly imperfect circular stamp. Under it, show a small TURN indicator and whose turn it is.

Numbers that have been called should receive a subtle physical-looking mark: a pencil circle, ink stamp, or translucent strike-through rather than a modern glowing button. The marking should feel satisfying and tactile.

Completed rows and columns should receive a distinctive colored highlighter stroke that looks manually drawn across the paper. Each completed line corresponds to a Bingo progression:

B → I → N → G → O

Display this progression beside each player's board as five small handwritten letters. When a player completes their first line, the B becomes highlighted; subsequent completed lines activate I, N, G, O. The completed line should remain permanently highlighted.

The center/top of the screen should contain a minimal title:

B I N G O

with each letter initially appearing as faint pencil writing. As the player progresses, each letter becomes stamped/highlighted.

Add a small “NUMBER LOG” section showing previously called numbers as tiny numbered circles, resembling a teacher's attendance sheet rather than a conventional HUD.

Include a compact bottom toolbar with:

NEW GAME | PAUSE | SETTINGS

Buttons should look like paper tabs or small label stickers rather than rounded modern UI buttons.

Typography should combine a clean readable sans-serif for functional information with a subtle handwritten/monospace typeface for numbers, annotations, and Bingo letters. Avoid excessive handwritten typography; readability remains important.

Use a restrained palette: warm paper, graphite/charcoal ink, muted red correction marks, faded blue pencil, and one distinctive accent color used for completed Bingo lines. Avoid neon colors, gradients, glossy UI, casino aesthetics, slot-machine imagery, cartoon characters, excessive shadows, and generic gaming UI.

Add subtle micro-interactions: paper movement when a number is marked, a quick pencil-circle animation, slight stamp animation when a Bingo letter activates, and a small paper vibration when a new number is called.

Overall mood: nostalgic school notebook + tabletop strategy game + modern minimalist interface.

The design should feel like someone took a physical Bingo sheet from an old notebook and turned it into a beautifully crafted indie game interface.

Make the interface practical for both desktop and future mobile adaptation, with large touch-friendly number cells and clear visual hierarchy.

Do not make it look like a casino Bingo game, gambling app, children's game, or generic mobile game. The identity should come entirely from the notebook/game-sheet concept.


Hand-drawn physicality is essential to the entire interface. Since the game exists on a paper/notebook surface, all text should look like it was personally written with a graphite pencil, rather than typed digitally. Use natural handwritten lettering with slight variations in pressure, spacing, and alignment. Numbers should look individually written by hand, with tiny imperfections between characters.

The gameplay boxes and Bingo grid must also look genuinely pencil-drawn by hand. Do not use perfectly straight geometric UI borders. Every line should have subtle inconsistencies: slightly different thickness, tiny wobbles, imperfect corners, occasional overlaps, and small variations in alignment, as if someone drew the entire board directly onto paper without a ruler.

The individual 5×5 cells should not look like computer-generated rectangles. Their boundaries should have the organic irregularity of pencil strokes. Some lines can be slightly darker where the pencil was pressed harder, while others can be faint or partially broken.

The same hand-drawn treatment should extend to buttons, labels, dividers, number circles, turn indicators, and the B-I-N-G-O progression. Everything should feel like it belongs to the same physical notebook page.

Avoid clean vector lines, perfectly symmetrical boxes, digital typography, polished UI borders, rounded SaaS-style components, or overly precise geometry. The goal is to create the illusion that a person sat down with a pencil and drew the entire game interface onto a sheet of paper, and the player is interacting with that physical drawing.
